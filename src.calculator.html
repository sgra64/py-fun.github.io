src.calculator.calculator module¶

class src.calculator.calculator.Calculator[source]¶

Bases: object

Singleton Calculator instance performs basic calculations on numbers.

Numbers can be given in various forms: as int, float, double or as string numbers, e.g. “123” or “1.600” or as Latin numbers “X”, as single digit words: “three” (English, 3), “cinco” (Spanish, 5), “семь” (Russian, 7), “X” (Latin, 10) or “三” (Chinese, sān 3).
